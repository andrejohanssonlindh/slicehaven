# Roadmap

Rough milestones. Each ends with something you can play on the phone.

## M0 — Foundations ✅ (2026-10-25)
Repo, deploy, rules engine skeleton, tech prototype scenario, Director's Room.

## M1 — One real scenario
- Final turn structure (after Q2/Q3).
- Monster turns: monster dice, simple AI (move toward, attack).
- Damage, shields, death, win/lose screens.
- First pixel art: floor tiles, walls, 1 hero, 2 monsters, dice UI.
- Story text box before and after.

## M2 — Campaign skeleton
- Overworld map scene, selectable locations.
- Campaign graph: scenarios unlock others; main arc + side quests.
- Save/load fully wired (party, campaign flags, gold).
- 3 scenarios linked together.

## M3 — Build-crafting
- Loot and gear (hero gear + die gear), shop.
- Level-ups / perks that change dice faces.
- Road events between scenarios (choices with consequences).

## M4 — Content
- 2–3 heroes, 6–8 monster types, a boss.
- The first act of the main arc + a few side quests.
- Music and sound.

## Later
- Home base / town (Frosthaven style).
- More regions.
