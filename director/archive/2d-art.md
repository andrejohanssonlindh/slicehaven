# Archive: the 2D hex art and pages

*Taken 2026-10-29, just before the 2D hex engine was removed. These are pictures; the code that drew them is kept in git under the tag **`2d-archive`** (checkout that tag and `npm run dev` to run any of it again).*

Some of these painters still live on in the 3D world, which paints its textures and sprite cards with them: people (`art/folk.ts`, `folkWalk.ts`), furniture and interiors (`furniture.ts`, `interior.ts`, `humble.ts`), shop goods (`shopItems.ts`), and the wall, roof and wood textures (`buildings.ts`, `houses.ts`). The rest (leaf trees, seasons, pond, shrubs, palisade, rocks, the village scene and the hex tiles) is only in the tag. To bring a piece back, take its painter from the tag into `src/art/` and give it a 3D use.
